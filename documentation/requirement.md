# Requerimientos

El sistema debe ser una memoria local del proyecto, el cual, registra desiciones, ideología, metodologías, contexto, estructura y todo lo necesario para seguir el hilo del proyecto. Sin embargo, tambien debe manejar como todo esta conectado mediante grafos de conocimiento tal como lo hace graphify.

La idea:

- Se inicializa una vez por proyecto
- Actualiza o crea el Agents.md con las indicaciones para el agente utilizado
- De manera autónoma debe almacenar y regisrar desiciones, contexto, metodología y todo lo relacionado.
- También debe poder generar y actualizar el grafo de conocimientos y las relaciones entre todas las funcionalidades del proyecto
